# Engineering Handbook

## Core expectations

- Keep code maintainable, reviewed, tested, and documented.
- Prefer small, reversible changes.
- Use explicit environment configuration and never commit secrets.
- Document APIs, schemas, migrations, deployment, and operational risks.
- Separate development, staging, and production where the system supports it.
- Treat logs, analytics, and datasets as possible sources of sensitive information.
