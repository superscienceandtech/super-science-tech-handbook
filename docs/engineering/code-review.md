# Code Review

Review for:
- Correctness and requirement coverage
- Security, privacy, authentication, and authorization
- Error handling and failure behaviour
- Tests and regression risk
- Readability and maintainability
- Database migration and backward compatibility
- Performance where material
- Documentation and operational impact

Reviewers should explain actionable concerns and distinguish blockers from suggestions. Authors should respond respectfully and update tests or documentation when behaviour changes.
