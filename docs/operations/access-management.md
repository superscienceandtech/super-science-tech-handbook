# Access Management

**Status:** Proposed baseline.

- Every user has an individual account; avoid shared credentials.
- Grant access based on role and task, using least privilege.
- Require MFA where supported, especially for privileged accounts.
- Use separate production credentials and restrict production access.
- Review access periodically and after role changes.
- Revoke access promptly at offboarding or contract end.
- Record who approved privileged access and why.
- Store credentials only in an approved secret manager.
