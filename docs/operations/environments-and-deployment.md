# Environments and Deployment

**Status:** Template / proposed baseline.

For every system, document:
- Local development, staging, and production environments (where applicable)
- Hosting provider, region, and system owner
- Configuration and secret-management method
- CI/CD workflow and required checks
- Database migration process
- Health checks, logs, metrics, alerts, and on-call contact
- Backup schedule, retention, and restore-test evidence
- Rollback or forward-fix procedure
- External dependencies and recovery steps

Environment URLs, hosting accounts, deployment commands, and production access owners: TBD. Never store secret values here.
