# Decision Log

Use Architecture Decision Records (ADRs) for decisions with meaningful long-term impact.

Suggested filename: `ADR-0001-short-title.md`

Each ADR should include:
- Status: Proposed / Accepted / Superseded / Rejected
- Date and decision owner
- Context and constraints
- Options considered
- Decision and rationale
- Consequences and risks
- Revisit trigger and related decisions

Do not mark a decision Accepted until the authorized owner approves it.
