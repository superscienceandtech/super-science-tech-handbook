# Roles and Responsibilities

**Status:** Role framework proposed; actual people and assignments are TBD.

| Role / function | Typical responsibility | Decision boundary |
|---|---|---|
| Founder / company lead | Strategy, priorities, resource allocation, final company decisions | Authority and delegation rules require confirmation |
| Business development / sales | Lead qualification, proposals, client communication | Cannot approve unbudgeted commitments unless delegated |
| Project / delivery lead | Scope, milestones, risks, coordination, acceptance | Works within approved scope and authority |
| Engineering lead | Architecture, technical standards, code quality | Security-sensitive changes follow security review |
| Software engineer | Implement, test, review, document assigned work | No production access without authorization |
| AI/ML researcher | Hypotheses, experiments, evaluation, reproducibility | Data use and publication require review |
| QA / testing | Test plans, defect reporting, release evidence | Release gate to be defined |
| DevOps / security owner | Environments, deployments, access, monitoring, incident coordination | Privileged access limited and audited |
| Operations / HR | Onboarding, internal process, records | Sensitive records stored in restricted systems |

One person may hold multiple roles in a small team. Assign named owners only after the founder confirms the organization chart.
