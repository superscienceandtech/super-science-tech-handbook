# Employee Onboarding

**Status:** Starter checklist — assign an onboarding owner before use.

## Before the first day
- [ ] Confirm role, manager, work contact, and start date in the appropriate HR system.
- [ ] Approve least-privilege access to email, GitHub, project tools, and required environments.
- [ ] Confirm confidentiality, IP, and other required agreements through the proper process.
- [ ] Assign a buddy or technical contact.

## First day
- [ ] Read this handbook and the Code of Conduct.
- [ ] Understand the three business pillars and current team priorities.
- [ ] Review security and incident reporting procedures.
- [ ] Configure development tools using approved setup guides.
- [ ] Confirm communication channels, meeting cadence, and working agreements.

## First week
- [ ] Set up the relevant repository and run its tests locally.
- [ ] Review architecture, active tasks, and decision records.
- [ ] Complete a small, reviewed starter task.
- [ ] Confirm goals and questions with the manager.

## Access and offboarding
Access must be approved, scoped to role, and removed promptly when no longer needed. Offboarding owner, timing, equipment handling, and records-retention process: TBD.
