# Security Baseline

**Status:** Proposed baseline — requires owner review.

- Use individual accounts and multi-factor authentication where available.
- Grant least-privilege access and review it periodically.
- Protect default branches and require reviewed changes.
- Keep credentials in an approved secret manager or environment configuration.
- Never commit `.env` files, private keys, access tokens, or customer data.
- Validate input and enforce authorization server-side on every sensitive action.
- Keep dependencies and runtime versions maintained.
- Minimize personal data; document purpose, access, retention, and deletion.
- Review data-processing and IP terms before using client assets for research or products.
- Maintain a private incident reporting channel and test recovery procedures.
